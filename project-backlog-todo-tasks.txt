Prompt-flow groups

The goal of prompt-flow groups is to avoid running the full 6-prompt sequence for every single ticket.
Instead, one Codex run should cover one coherent implementation or review area.

Use these rules:
	•	Run the full 6-prompt flow only for the group anchor task.
	•	Cover the linked tasks inside the same run unless the group produces a clear blocker or split.
	•	Use prompts 1 to 3 only for review/decision-heavy groups when no immediate code change is needed.
	•	Create a new standalone 6-prompt run only when a linked task becomes materially larger than the anchor scope.
